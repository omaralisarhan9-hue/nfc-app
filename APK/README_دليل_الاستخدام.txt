============================================================
              تطبيق إدارة وبث بطاقات NFC الذكية
============================================================

مرحباً بك! تم استخراج حزمة التطبيق الكاملة على سطح المكتب بنجاح.

محتويات المجلد:
------------------------------------------------------------
1. flutter_app/ :
   - مشروع تطبيق الأندرويد الكامل المكتوب بـ Flutter.
   - يدعم: قراءة المعرف العتادي UID، معرفة نوع الشريحة والسعة،
     قراءة كافة المحتويات وتفريغ الـ Hex Dump، التعديل على البيانات،
     إعادة التشفير الأصلي بعد التعديل، خانة المهم ⭐، وبث/عكس البطاقة
     من الموبايل لقارئات الأبواب الذكية عبر HCE.

2. بناء_ملف_APK.bat :
   - ملف تنفيذي لبناء ملف الـ APK مباشرة عند تثبيت Flutter SDK.

3. تشغيل_التطبيق_في_المتصفح.bat :
   - اضغط عليه مرتين لتشغيل تطبيق الويب (Web NFC PWA) فورا
     في المتصفح وتجربة قراءة وتعديل وتشفير البطاقات بنقرة واحدة.

4. .github/workflows/build-apk.yml :
   - سير عمل GitHub Actions لبناء ملف الـ APK مجانا في السحابة
     وتنزيله دون الحاجة لتثبيت أي أدوات برمجية على جهازك.

============================================================
